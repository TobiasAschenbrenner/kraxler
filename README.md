# kraxler

An offline-first climbing guide for iOS.

Kraxler helps climbers discover climbing areas and routes, view their current
location on a map, save routes, and keep a personal tick list. Selected content
will be available offline for use in areas with poor mobile reception.

## Project status

Kraxler is a ten-week solo capstone project. The intended outcome is a polished,
functional prototype distributed through TestFlight rather than a public App
Store release.

## Repository structure

- `ios/` — native iOS application built with Swift and SwiftUI
- `backend/` — Node.js and Express API
- `docs/` — product, architecture, API, and development decisions
- `postman/` — Postman collections and environments for exercising the API

## Planned core features

- Browse and search climbing areas and routes
- Filter routes by grade, style, length, and number of pitches
- Show the user's current location alongside climbing areas on a map
- Download selected climbing data for offline use
- Register and sign in
- Save routes and mark completed climbs
